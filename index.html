Ordo

版本 0.1.7-beta.4  ·  适用 macOS 14 及以上  ·  请在 Mac 上打开本页

这是内测版，不是成品。下面每一条都是实话，包括不好的部分。

Ordo 是什么

Ordo 是一个装在 Mac 上的工作记录与复盘工具。你开始工作时按一下「开始录制」，它在后台按需截屏并记录你切了哪些窗口、做了哪些操作；停下来的时候，它把这一段时间交给视觉大模型去看，告诉你这段时间你其实在做什么任务、时间花在哪儿了。

它想解决的问题很具体：一天过完，说不清自己干了什么。不是靠你手动记工时，而是靠它自己看。

内测阶段能用的就是这条主线：录一段 → 让 AI 看懂 → 出一份时间与任务的分布。更远的规划（主动提醒、代你执行）还没做进来，不要按宣传页的期待来验收这个版本。

装之前，请务必先看这三件事

第一 · 它会截你的屏，而且截图会上传

截图先在本机压缩到宽 1280、JPEG 质量 0.7，然后编码后发到阿里云百炼（dashscope.aliyuncs.com）交给通义千问的视觉模型分析。上传的是你整个屏幕的画面，不是某个窗口——所以如果屏幕上同时有微信聊天、密码管理器、财务表格，它们都在那张图里。

这一点在 0.1.7 之前是说错的：0.1.6 的首次引导页写着「你的数据完全存储在本地，不会上传到任何服务器」，那句话是错的，是我的疏漏。0.1.7 已经改掉，现在引导页如实写明截图需要发送给阿里云百炼做内容识别、这是分析功能的前提。如果你手上还是 0.1.6，看到的仍是错的那句，以本页为准。

第二 · 涉密和敏感场景请直接停掉录制

停止录制之后不会再有任何截图产生，也不会有任何上传。菜单栏图标在录制时是红色实心圆点并显示计时，没在录制时是一个眼睛图标——一眼就能确认当前状态。

第三 · 如果你是从旧版升上来的，升上来之后必须重新授权一次

0.1.7-beta.4 已经完成 Apple 公证，签名身份从自签名换成了正式的 Apple Developer ID。新装的同学从此双击即开，不会再有任何拦截弹窗——之前那套「点完成 → 去系统设置 → 仍要打开」可以忘掉了。

代价落在老用户身上：macOS 按签名摘要记住权限授权，签名身份一换，你之前授的辅助功能／屏幕录制／输入监控会一起失效。麻烦在于系统设置里那几个开关看起来还是开着的，实际已经不生效，而且 Ordo 不报错，只是读不到窗口标题、分析质量下降——很容易被当成「AI 突然变笨了」。

处理办法在「更新」一节最后，一分钟的事。这应该是最后一次因为换包而需要重新授权。

安装

方式一：正常下载安装（推荐）

  1. 浏览器打开 cookey.com.cn/updates/Ordo-latest.dmg 下载，双击挂载。
  2. 把 Ordo 拖进「应用程序」文件夹。
  3. 从「应用程序」文件夹里打开它，不要在挂载出来的那个磁盘映像窗口里直接双击。

没有第四步。这一版已经过 Apple 公证并装订了票据，Gatekeeper 直接放行，离线也一样。如果你还看到「无法验证开发者」或者「已损坏」，说明你手上的包不是这一版，重新下一次。

第 3 步那句「从应用程序里打开」不是废话：直接在磁盘映像或「下载」目录里双击运行，macOS 会把它当成临时位置的程序对待，权限授权和数据目录都可能对不上，表现出来就是「授权了但不生效」。拖进「应用程序」再打开，这类问题就没有了。

方式二：一行命令（适合升级，或者公司统一装机）

打开「终端」（Terminal，聚焦搜索 terminal 回车），把下面整段一次性粘贴进去，回车：

curl -fL https://cookey.com.cn/updates/Ordo-latest.dmg -o /tmp/Ordo.dmg
hdiutil attach -nobrowse -quiet /tmp/Ordo.dmg -mountpoint /tmp/OrdoDMG
osascript -e 'quit app "Ordo"' 2>/dev/null
[ -e /Applications/Ordo.app ] && mv /Applications/Ordo.app ~/.Trash/Ordo-$(date +%s).app
ditto /tmp/OrdoDMG/Ordo.app /Applications/Ordo.app
hdiutil detach /tmp/OrdoDMG -quiet
open /Applications/Ordo.app

它做的事按顺序是：下载安装包 → 挂载 → 退掉可能正在运行的旧版本 → 把旧版本挪进废纸篓（不是直接删，你随时能捞回来）→ 拷进「应用程序」→ 卸载安装包 → 启动。

拷贝这一步用的是 ditto 而不是 cp -R：cp 不保证完整保留 App 包里的扩展属性和签名结构，拷坏了会表现成「装完打不开」或者签名校验失败。ditto 是 macOS 自带的，专门干这件事。

和上一版相比少了一行 xattr -dr com.apple.quarantine——那是自签名时代用来绕开 Gatekeeper 的，现在包已经公证，不需要了，留着反而会掩盖「包被改坏了」这类真问题。

首次启动：三步引导

第一步，填个名字。用来让 Ordo 认出「你自己」，不至于把你的名字当成一个联系人统计进去。

第二步，授权。需要三个系统权限，都会跳到系统设置对应位置，授权完回来点「刷新权限状态」：

屏幕录制截屏用。不给这个，Ordo 什么都看不到，等于不能用。
辅助功能读取屏幕上的窗口标题、按钮这类界面结构信息。用来判断你在哪个 App 的哪个界面，比单看图片准得多。
输入监控记录键鼠动作的时机（什么时候有操作、有多密集），用来判断你是在专注干活还是在发呆，以及决定什么时候值得截一张图。不记录你按了哪些具体的键，不做键盘记录。

授权时如果系统设置里已经有一条旧的 Ordo 记录，先把它删掉再重新加，否则可能出现「看着是开着的但实际不生效」的情况。

第三步，AI 分析（可选）。内测期我内置了一份共享的免费额度，装完直接能用，不用填任何 key。额度分两档：每台机器每天 6000 次截图分析 + 500 次 AI 拆解/排程——这个量足够挂满一整个工作日，正常用不到头，它更像是防程序跑飞的保险丝（0.1.7-beta.2 之前是一天 50 次两者共用，一次录制就能打穿，已经修了）。这份额度是我自己付费的，所以：如果你打算长期用或者用得比较重，建议去 阿里云百炼 申请一个自己的 API Key 填进去（设置里那一栏），额度不限，费用按你自己的账号走。

怎么用

开始一段记录。主窗口顶部有「开始录制」按钮，菜单栏图标点开也有。开始之后它不会一直疯狂截屏——只在检测到你切换窗口、有明显操作变化的时候截，另外每 5 秒有一次心跳兜底。你正常干活就行。

停下来看结果。点「停止录制」，这一段成为一条「会话」。Ordo 会把这段时间的截图交给模型分析，出任务判断和时间分布。会话越长分析越久，几分钟的会话通常几十秒内出结果。

四个页面：

  • 今日 —— 今天的录制情况和当前状态，也是启停录制的地方。
  • 洞察 —— 从多天数据里归纳的规律，比如时间都花在哪类事情上。数据少的时候这页会很空，正常。
  • 历史 —— 所有会话列表，按今天／本周／本月筛。点进单条会话可以逐张回看截图，以及看模型对这段时间的判断。
  • 设置 —— 名字、API Key、主题这些。
注意有两个设置界面

这是这个版本的一个毛病：主窗口侧边栏里的「设置」只有一部分选项；按 ⌘, 打开的那个独立设置窗口里才有无感录制（开了之后启动 App 就自动开始录，默认关）、视觉分析模型选择和存储位置。要找的东西在侧边栏没有，就去 ⌘, 那个窗口翻。

更新相关的三样——当前版本号、自动检查更新开关、立即检查更新按钮——0.1.7-beta.2 起在主窗口侧边栏的「设置」里也有了一份（最下面的「关于与更新」），不用再去 ⌘, 里找。再早的版本只有 ⌘, 那个窗口里有，等于绝大多数人根本看不到这个入口，这是我的疏漏。

退出：⌘Q。退出时它会先把当前录制的数据存好再退。

你的数据在哪，怎么删

所有东西都在这一个目录里：

~/Library/Application Support/Ordo/

Finder 里按 ⇧⌘G 粘贴上面这个路径就能直接过去。

里面有截图（captures/<时间戳>/screenshots/）、录音、模型分析结果、会话索引。

会长得很快。我自己 50 个会话大约占了 465 MB，主要是截图。这个版本没有自动清理，也没有保留期设置，需要你自己去看。在 App 内删除会话是移到废纸篓，不是直接抹掉，误删能捞回来。

彻底卸载 = 把「应用程序」里的 Ordo 拖进废纸篓 + 把上面那个目录拖进废纸篓 + 在「系统设置 → 隐私与安全性」里把屏幕录制／辅助功能／输入监控三处的 Ordo 移除。

关于上传，把话说尽

会上传的只有压缩后的屏幕截图，发往阿里云百炼做分析。麦克风录音只在本机存成 m4a 文件，不上传、不转写（这个版本其实还没用上这些录音）。除此之外没有任何数据发到我这里——我这边收不到你的截图，也没有任何服务端在收集你的使用数据。反过来说这也意味着：出问题我看不到，只能靠你告诉我。

已知限制（这个版本就是这样，不用报）

  1. 首次打开会被系统拦 —— 尚未公证 —— 0.1.7-beta.4 已解决，包已通过 Apple 公证并装订票据，双击即开。
  2. 一启动可能就开始跑分析 —— 如果你机器上已经有旧的录制数据，Ordo 启动时会自己去补分析那些老会话，不需要你点任何按钮。额度抬高之后这不会让你没得用，但它确实会在你没要求的时候悄悄跑起来，该有个开关，还没做。
  3. 设置里的「图片质量」滑块目前不起作用 —— 拖它没有任何效果，实际用的一直是固定的 1280 宽／0.7 质量。
  4. 多屏用户注意 —— 截的是所有显示器拼在一起的整张画面，不是单屏，也不能只截某个窗口。
  5. 麦克风录音只在特定 App 前台时才自动开 —— 认的是飞书／Lark／Slack／Zoom／Google Meet／腾讯会议／Teams／Webex 这几个。钉钉和微信不在名单里，用它们开会不会自动录音。
  6. 界面里偶尔会冒出「L3」这类词 —— 开发时的内部说法，不是你需要理解的概念，会清掉。
  7. 没有开机自启，没有通知，没有全局快捷键 —— 每次得自己打开 App。
  8. 「洞察」页在数据少的时候基本是空的 —— 需要攒几天。
  9. App 里还没有反馈入口 —— 一直想加还没加，我不再报具体版本号了，做好了会在更新说明里写。眼下请用下面「反馈」一节的方式找我。
  10. 装了公司安全软件的机器，自动更新可能失败 —— 之前我写的是「必然失败，原因是自签名」，那条因果我自己复测时没复现出来，现在降级为嫌疑。这一版换成公证包之后请再试一次，仍然失败就用「更新」一节里的手动办法，并告诉我。
  11. 0.1.7-beta.4 这次换签名，辅助功能／屏幕录制／输入监控授权一定会失效 —— 系统设置里开关看着还是开的，实际不生效，而且 Ordo 不会报错，只是读不到窗口标题、分析变差，很容易被当成「AI 变笨了」。处理办法见「更新」一节，移除再重加即可。这应该是最后一次。
  12. 免费额度是内测期的临时安排 —— 每台机器各自计数（每天 6000 次截图分析 + 500 次拆解/排程），由我个人承担。如果哪天集体失效，App 会明确说明「是我们这边的问题，不是你的」——看到这句话告诉我一声就行，不必去给自己的账号充值；长期使用请填自己的 API Key。

更新

0.1.6-beta.2 起接入了自动更新（Sparkle）。它每天检查一次 cookey.com.cn 上的更新源，检查到新版本会自动下载并装上，你不需要点任何东西，通常在下一次启动 Ordo 时就已经是新版了。想手动查：主窗口侧边栏「设置」→ 最下面「关于与更新」→「立即检查更新」（0.1.7-beta.2 起才有；再早的版本只能按 ⌘, 打开独立设置窗口，那里也有一份）。

0.1.7-beta.4：签名身份已经换了，请重新授权一次

这一版把签名从自签名换成了 Apple Developer ID 并完成公证。应用功能一行代码都没改，唯一的变化就是签名——以及随之而来的权限失效。

怎么做（一分钟）：先退出 Ordo，然后打开「系统设置 → 隐私与安全性 → 辅助功能」，选中 Ordo 点 − 移除，再点 + 添加 /Applications/Ordo.app，确认开关是开的。「屏幕录制」和「输入监控」两栏做同样的操作。三项都弄完再启动 Ordo。

为什么要移除再添加、而不是把开关关掉再打开：系统里记的是一份「签名要求」，只有移除重加才会按当前这个包重新写一份。开关来回拨有可能仍然沿用旧的那份，表现出来就是「开着但不生效」。

好消息是这应该是最后一次。自签名时代系统按二进制摘要记权限，每重新打一次包就会变；换成 Developer ID 之后改按证书记，以后发新版不会再掉。

如果你的机器装了公司安全软件，之前自动更新一直失败

先说清楚已知和未知。已知：Sparkle 等待安装器响应的超时是写死在代码里的 7 秒，超过就失败；公司统一下发的安全软件（EDR 那类）会在程序启动时插一道强制检查，把启动拖慢。之前的说法是「自签名会被拖到 11 秒以上，所以必然失败」，但我在本机复测时并没有复现出那个数字，所以这条因果现在只能算作嫌疑，不是结论。

实际怎么办：这一版已经是公证包了，如果你之前自动更新一直失败，请在升到 0.1.7-beta.4 之后再试一次。如果还是失败，用下面的手动办法，并且告诉我一声——那说明真正的原因不在签名上，我需要重新查。

手动升级：把「安装」一节里方式二那段命令原样再跑一遍就行。它可以重复执行：会先退掉正在运行的 Ordo，把旧版本挪进废纸篓（不是删，随时能捞回来），再把新版本装进「应用程序」并启动。你的录制数据和设置都不在 App 包里，不会丢。

反馈

最有用的反馈，按优先级：

  1. 崩溃或者卡死 —— 什么操作之后发生的。如果 App 崩了，~/Library/Logs/DiagnosticReports/ 里会有一个 Ordo-....ips 文件，发给我。
  2. AI 判断错了 —— 它说你在做 A、你其实在做 B。这类反馈对我最值钱，请顺手说一下当时你实际在干什么。
  3. 哪一步让你卡住了或者觉得莫名其妙 —— 尤其是安装和首次授权这一段。
  4. 你希望它主动帮你做什么 —— 这决定后面往哪走。
