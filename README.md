# Ordo 内测说明书

> 版本 0.1.6-beta.2 · 适用 macOS 14 及以上 · Apple Silicon 与 Intel 均可
> 这是内测版，不是成品。下面每一条都是实话，包括不好的部分。

网页版：<https://liyamaaa.github.io/ordo-docs/>

## Ordo 是什么

Ordo 是一个装在 Mac 上的工作记录与复盘工具。你开始工作时按一下「开始录制」，它在后台按需截屏并记录你切了哪些窗口、做了哪些操作；停下来的时候，它把这一段时间交给视觉大模型去看，告诉你这段时间你其实在做什么任务、时间花在哪儿了。

它想解决的问题很具体：**一天过完，说不清自己干了什么。** 不是靠你手动记工时，而是靠它自己看。

内测阶段能用的就是这条主线：录一段 → 让 AI 看懂 → 出一份时间与任务的分布。更远的规划（主动提醒、代你执行）还没做进来，不要按宣传页的期待来验收这个版本。

## 装之前，请务必先看这三件事

**第一，它会截你的屏，而且截图会上传。** 截图先在本机压缩到宽 1280、JPEG 质量 0.7，然后编码成 base64 发到阿里云百炼（`dashscope.aliyuncs.com`）交给通义千问的视觉模型分析。**上传的是你整个屏幕的画面**，不是某个窗口——所以如果屏幕上同时有微信聊天、密码管理器、财务表格，它们都在那张图里。

如果 App 内的引导文案与本页描述不一致，**以本页为准**；引导文案会在下个版本更新。

**第二，涉密和敏感场景请直接停掉录制。** 停止录制之后不会再有任何截图产生，也不会有任何上传。菜单栏图标在录制时是红色实心圆点并显示计时，没在录制时是一个眼睛图标——一眼就能确认当前状态。

**第三，这个版本还没有做 Apple 公证，首次打开会被系统拦一下。** 下面「安装」一节给了两条路，第一条不会遇到任何拦截弹窗。公证正在办（等苹果开发者账号审核），办完之后就跟正常 App 一样双击即开。

## 安装

### 方式一：一行命令（推荐，不会被系统拦）

打开「终端」（Terminal，聚焦搜索 terminal 回车），把下面整段一次性粘贴进去，回车：

```bash
curl -fL https://cookey.com.cn/updates/Ordo-latest.dmg -o /tmp/Ordo.dmg
hdiutil attach -nobrowse -quiet /tmp/Ordo.dmg -mountpoint /tmp/OrdoDMG
osascript -e 'quit app "Ordo"' 2>/dev/null
[ -e /Applications/Ordo.app ] && mv /Applications/Ordo.app ~/.Trash/Ordo-$(date +%s).app
cp -R /tmp/OrdoDMG/Ordo.app /Applications/
hdiutil detach /tmp/OrdoDMG -quiet
xattr -dr com.apple.quarantine /Applications/Ordo.app 2>/dev/null
open /Applications/Ordo.app
```

它做的事按顺序是：下载安装包 → 挂载 → 退掉可能正在运行的旧版本 → 把旧版本挪进废纸篓（不是直接删，你随时能捞回来）→ 拷进「应用程序」→ 卸载安装包 → 清掉下载隔离标记 → 启动。

之所以推荐这条路：用 `curl` 下载的文件不带 macOS 的「隔离标记」，Gatekeeper 就不会介入，你不会看到任何「无法验证开发者」的弹窗。

### 方式二：图形界面（会被拦一次，需要五步放行）

1. 浏览器打开 `https://cookey.com.cn/updates/Ordo-latest.dmg` 下载，双击挂载，把 Ordo 拖进「应用程序」。
2. 双击 Ordo，会弹出「Apple 无法验证 Ordo 是否包含恶意软件」，点「完成」。看起来像失败了，其实是正常流程的第一步。
3. 打开「系统设置 → 隐私与安全性」，滑到下面的「安全性」区域，会看到一行「已阻止"Ordo"以保护 Mac」，右边有「仍要打开」按钮。
4. 点「仍要打开」，再确认一次。
5. 输入你的 Mac 登录密码。之后就正常了，只有第一次需要这样。

> macOS 15 之后，老办法「右键 → 打开」已经被苹果取消了，只剩上面这条系统设置里的路。别在右键菜单里找了。

## 首次启动：三步引导

**第一步，填个名字。** 用来让 Ordo 认出「你自己」，不至于把你的名字当成一个联系人统计进去。

**第二步，授权。** 需要三个系统权限，都会跳到系统设置对应位置，授权完回来点「刷新权限状态」：

- **屏幕录制** —— 截屏用。不给这个，Ordo 什么都看不到，等于不能用。
- **辅助功能** —— 读取屏幕上的窗口标题、按钮这类界面结构信息。用来判断你在哪个 App 的哪个界面，比单看图片准得多。
- **输入监控** —— 记录键鼠动作的**时机**（什么时候有操作、有多密集），用来判断你是在专注干活还是在发呆，以及决定什么时候值得截一张图。**不记录你按了哪些具体的键**，不做键盘记录。

授权时如果系统设置里已经有一条旧的 Ordo 记录，先把它删掉再重新加，否则可能出现「看着是开着的但实际不生效」的情况。

**第三步，AI 分析（可选）。** 内测期内置了一份免费额度，每台机器每天 50 次模型调用，装完直接能用，不用填任何 key。这份额度由我个人承担，所以：如果你打算长期用或者用得比较重，建议去[阿里云百炼](https://bailian.console.aliyun.com/)申请一个自己的 API Key 填进去（设置里那一栏），额度不限，费用按你自己的账号走。

## 怎么用

**开始一段记录。** 主窗口顶部有「开始录制」按钮，菜单栏图标点开也有。开始之后它不会一直疯狂截屏——只在检测到你切换窗口、有明显操作变化的时候截，另外每 5 秒有一次心跳兜底。你正常干活就行。

**停下来看结果。** 点「停止录制」，这一段成为一条「会话」。Ordo 会把这段时间的截图交给模型分析，出任务判断和时间分布。会话越长分析越久，几分钟的会话通常几十秒内出结果。

**四个页面**：

- **今日** —— 今天的录制情况和当前状态，也是启停录制的地方。
- **洞察** —— 从多天数据里归纳的规律，比如时间都花在哪类事情上。数据少的时候这页会很空，正常。
- **历史** —— 所有会话列表，按今天／本周／本月筛。点进单条会话可以逐张回看截图，以及看模型对这段时间的判断。
- **设置** —— 名字、API Key、主题这些。

**注意有两个设置界面**，这是这个版本的一个毛病：主窗口侧边栏里的「设置」只有一部分选项；按 `⌘,` 打开的那个独立设置窗口里才有**无感录制**（开了之后启动 App 就自动开始录，默认关）、**视觉分析模型**选择、**存储位置**，以及**自动更新**开关。要找的东西在侧边栏没有，就去 `⌘,` 那个窗口翻。

**退出**：`⌘Q`。退出时它会先把当前录制的数据存好再退。

## 你的数据在哪，怎么删

所有东西都在这一个目录里：

```
~/Library/Application Support/Ordo/
```

里面有截图（`captures/<时间戳>/screenshots/`）、录音、模型分析结果、会话索引。Finder 里按 `⇧⌘G` 粘贴上面这个路径就能直接过去。

**会长得很快。** 我自己 50 个会话大约占了 465 MB，主要是截图。这个版本**没有自动清理**，也没有保留期设置，需要你自己去看。在 App 内删除会话是移到废纸篓，不是直接抹掉，误删能捞回来。

**彻底卸载** = 把「应用程序」里的 Ordo 拖进废纸篓 + 把上面那个目录拖进废纸篓 + 在「系统设置 → 隐私与安全性」里把屏幕录制／辅助功能／输入监控三处的 Ordo 移除。

**关于上传，把话说尽**：会上传的只有压缩后的屏幕截图，发往阿里云百炼做分析。麦克风录音只在本机存成 m4a 文件，**不上传、不转写**（这个版本其实还没用上这些录音）。除此之外没有任何数据发到我这里——我这边收不到你的截图，也没有任何服务端在收集你的使用数据。反过来说这也意味着：**出问题我看不到，只能靠你告诉我。**

## 已知限制（这个版本就是这样，不用报）

1. **首次打开会被系统拦** —— 尚未公证，见上文。
2. **App 内引导文案与实际行为的描述不一致** —— 以本页描述为准，下个版本更新文案。
3. **一启动可能就开始烧额度** —— 如果你机器上已经有旧的录制数据，Ordo 启动时会自己去补分析那些老会话，不需要你点任何按钮。所以有可能你刚打开 App，今天的 50 次免费额度就少了一截。这个行为该有个开关，还没做。
4. **设置里的「图片质量」滑块目前不起作用** —— 拖它没有任何效果，实际用的一直是固定的 1280 宽／0.7 质量。
5. **多屏用户注意** —— 截的是所有显示器拼在一起的整张画面，不是单屏，也不能只截某个窗口。
6. **麦克风录音只在特定 App 前台时才自动开** —— 认的是飞书／Lark／Slack／Zoom／Google Meet／腾讯会议／Teams／Webex 这几个。**钉钉和微信不在名单里**，用它们开会不会自动录音。
7. **界面里偶尔会冒出「L3」这类词** —— 开发时的内部说法，不是你需要理解的概念，会清掉。
8. **没有开机自启，没有通知，没有全局快捷键** —— 每次得自己打开 App。
9. **「洞察」页在数据少的时候基本是空的** —— 需要攒几天。
10. **App 里还没有反馈入口** —— 计划在 0.1.7 加，眼下请用下面的方式找我。
11. **免费额度是内测期的临时安排** —— 每台机器每天 50 次，由我个人承担。如果哪天集体失效，多半是额度用尽了，告诉我一声；长期使用请填自己的 API Key。

## 更新

这个版本开始接入了自动更新（Sparkle）。它会定期检查 `cookey.com.cn` 上的更新源，有新版本会弹提示，你点一下就升级完了，不需要重新走安装流程。想手动查：`⌘,` 打开设置窗口 → 「立即检查更新」。

**有一次性的例外要提前打招呼**：等苹果开发者账号下来之后，我会把签名身份从现在的自签名换成正式的 Apple Developer ID 并做公证。自动更新本身不受影响，会正常升上去；但 macOS 是按签名身份来记权限的，**签名一换，你之前授的屏幕录制／辅助功能／输入监控会失效，需要在系统设置里重新授一次**。到时候我会明确通知。这个动作只发生一次，之后不会再有。

## 反馈

最有用的反馈，按优先级：

1. **崩溃或者卡死** —— 什么操作之后发生的。如果 App 崩了，`~/Library/Logs/DiagnosticReports/` 里会有一个 `Ordo-....ips` 文件，发给我。
2. **AI 判断错了** —— 它说你在做 A、你其实在做 B。这类反馈对我最值钱，请顺手说一下当时你实际在干什么。
3. **哪一步让你卡住了或者觉得莫名其妙** —— 尤其是安装和首次授权这一段。
4. **你希望它主动帮你做什么** —— 这决定后面往哪走。
